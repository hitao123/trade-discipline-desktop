# 守拙交易纪律

一个只在本机运行的 macOS 交易纪律记录工具。它不会连接券商、不会发送订单，也不会代替你做买卖决定；真实交易仍由你在券商 App 完成，本应用只负责交易前计划、交易后补录、纪律校验、持仓重放、收盘榜单、复盘和审计。

## 安装与启动

1. 打开 `守拙交易纪律-0.1.0-arm64.dmg`。
2. 将“守拙交易纪律”拖到“应用程序”。
3. 首次启动若 macOS 提示应用未签名，请在 Finder 中右键应用并选择“打开”，或前往“系统设置 → 隐私与安全性”确认打开。

当前安装包适用于 Apple 芯片 Mac（arm64），没有 Apple 开发者签名或公证。

## 建议的日常顺序

1. 在“市场榜单”收盘后刷新沪深股票成交额前 20 和 ETF 前 10；只把候选加入观察名单。
2. 在“交易计划”先填写逻辑、证伪、已计价预期、未来证据、逻辑破坏条件、退出条件、仓位和情绪。
3. 计划只有通过整手、资金、累计亏损、中国科技敞口、浮亏禁加仓、冷静期和腾讯顺序门槛后才显示“合格”。被拒绝的计划也会保留。
4. 在券商 App 自行交易后，到“成交补录”填写实际人民币扣款或到账。无计划、拒绝计划、过期计划、超计划数量等事实仍能保存，但会标为严重违规并启动冷静期。
5. 如果成交录错，不删除原记录：填写原因并“追加冲正”，再补录正确成交。
6. 每周在“每周复盘”只写事实和下一周唯一允许动作。

## 初始纪律边界

- 统一纪律账户：人民币 200,000 元。
- 累计亏损警戒线：15,000 元；红线：20,000 元。
- 中国大型科技绝对敞口上限：80,000 元。
- 腾讯 `0700.HK`、阿里巴巴 `9988.HK`：每手 100 股，基础上限各 100 股。
- 先建立阿里计划；腾讯需经过至少 20 个交易日观察、纪律分不低于 90 分，且中国科技持仓不处于亏损状态。
- 不允许对浮亏标的加仓，也不允许用另一只中国科技股进行摊平。
- 卖出原因使用 `T / B / R / C`：目标或估值、逻辑破坏、风险退出、组合约束。
- 严重违规冷静期递进：首次 5 个交易日、第二次 20 个交易日、第三次起 30 个自然日。

港股持仓的参考市值按最新收盘价并使用规则中的保守港币兑人民币折算率计算；现金和成本始终以实际人民币结算金额为准。

## 数据、修改记录与备份

- 数据保存在当前 Mac 的 Electron 应用数据目录中，核心文件为 `discipline.db`。
- 规则修改会创建新版本，必须填写原因；旧计划继续引用旧规则。
- 计划修改会写入修订表和审计记录，不会无痕覆盖。
- 成交与冲正是不可变事件；持仓和现金由事件重新计算。
- 规则修改和 CSV 批量导入前会自动备份，最多保留最近 20 个自动备份。
- “规则与设置”可导出完整 `.db` 备份；恢复前会先校验文件并保护当前数据库。
- “打开日志目录”可直接查看本地后端日志。日志不记录完整的自由文本交易理由。

## 收盘榜单与 CSV 备用导入

自动行情使用公开收盘数据，只用于榜单和参考价格。自动获取失败时，最近一次成功快照不会被覆盖。可以导入 [CSV 格式示例](docs/CSV格式示例.csv)：

```text
trade_date,market,code,name,asset_type,close,change_pct,turnover
```

- `trade_date`：`YYYY-MM-DD`
- `market`：`SH` 或 `SZ`
- `asset_type`：`stock` 或 `etf`
- `close`：收盘价，人民币元
- `change_pct`：涨跌幅百分数，例如 `1.25`
- `turnover`：成交额，人民币元

导入会先显示有效行、错误行、重复行以及最终股票前 20/ETF 前 10；只有确认后才会整批写入。

## 开发验证

需要 Go、Node.js 和 pnpm。安装依赖后执行：

```bash
pnpm verify
pnpm build:mac
```

`pnpm verify` 会依次运行 Go 测试、Vue/Electron 测试、类型检查和完整构建。详细验收证据见 [验收清单](docs/验收清单.md)。
