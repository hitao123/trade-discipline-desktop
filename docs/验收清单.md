# Plain Rule 验收清单

最近更新：2026-08-23；目标平台：macOS Apple Silicon。

1. **通过** — 打包应用在独立临时数据目录中启动，无需开发服务器；Go sidecar、SQLite 和 Electron 窗口均正常。
2. **通过** — 空库迁移测试验证初始资金 200,000 元、损失红线 20,000 元、中国科技上限 80,000 元。
3. **通过** — 规则表格测试验证腾讯/阿里 100 股整手；150 股计划被拒绝但仍入库。
4. **通过** — 计划表单覆盖理由、证伪、已计价预期、证据、逻辑破坏、退出、风险和情绪字段。
5. **通过** — 服务测试验证违规成交在一次事务中写成交、违规、冷静期和审计，并照常更新持仓。
6. **通过** — 事件重放测试覆盖现金、人民币加权成本、部分卖出、已实现盈亏、最新收盘浮盈亏和冲正。
7. **通过** — 规则修改生成新版本、原因与审计；计划修订写独立修订记录；历史计划规则引用不变。
8. **通过** — 每周复盘保存用户内容、自动组合指标和纪律评分。
9. **通过** — 公开数据适配器独立生成沪深股票成交额前 20 与 ETF 前 10 快照；真实数据冒烟成功。
10. **通过** — CSV 测试覆盖 BOM、坏行、重复、预览摘要、确认摘要锁和事务导入。
11. **通过** — 榜单界面只提供“加入观察”，组件测试确认不存在买入或下单按钮。
12. **通过** — 备份测试覆盖 SQLite 文件头、完整性、迁移版本、导出和恢复前保护。
13. **通过** — 应用不含登录、券商 API、真实委托或自动交易入口；界面持续提示“只补录，不发送订单”。
14. **通过** — Go、Vue、Electron 单元/集成测试、TypeScript 检查、完整构建和 macOS arm64 打包均通过。
15. **通过** — sidecar 使用结构化本地日志；后端离线、数据库、行情和 CSV 错误均有中文提示及重试/备用入口。
16. **通过** — 数据库迁移到 schema 2，日线和市场指标均按观察版本追加保存；重复拉取不制造重复点，公开源修正值不会无痕覆盖。
17. **通过** — 收盘刷新增量保存 A 股成交额和南向资金成交净买额；接口支持近 1 个月/3 个月查询并在部分来源失败时回退最近成功缓存。
18. **通过** — 榜单证券历史按需加载，同一启动会话只自动补齐一次；手动重新获取仍可显式刷新。
19. **通过** — 折线图覆盖单点、等值、跨零、空状态和缓存状态；涨跌口径及南向净卖出负值可访问文本均已验证。
20. **通过** — 数据库兼容迁移至 schema 7；市场快照持久化组件级健康状态，极速成交原子创建待复盘记录，并预留只追加的成交参考汇率观察表。
21. **通过** — 收盘榜单、ETF、报价、A 股成交额、南向资金和价格提醒分别记录状态、来源、来源时间与最近成功时间；一个来源失败不会覆盖其他组件的成功状态。
22. **通过** — 实时榜单与报价执行交易时段及时间戳新鲜度校验；前一交易日、未来时间和不完整备用报价不会保存成实时快照，也不会触发价格提醒。
23. **通过** — 个股公开报价主来源 EOF 时可切换独立备用源；备用源必须完整覆盖请求证券并通过新鲜度验证，否则保留本地缓存。
24. **通过** — 市场页使用简洁数据健康条展示“实时 / 延迟 / 本地缓存 / 暂不可用”，不向用户铺开完整请求地址和底层 EOF 错误。
25. **通过** — 极速留痕只需证券、方向、数量、均价和实际人民币结算；100 股港股满足 `min=100, step=100`，保存后同一事务立即更新持仓、现金、违规/冷静期、审计和待复盘状态。
26. **通过** — 港股不使用估算汇率入账，必须填写券商实际人民币扣款/到账；人民币证券自动预填且允许按实际费用修正。
27. **通过** — 无计划和纪律违规成交仍能如实保存；每笔极速成交进入逐笔事后复盘队列，未完成时服务端和界面均阻止提交本周复盘。
28. **通过** — 极速留痕、待复盘、市场数据健康、备用报价和旧有成交/冲正流程均有 Go 或 Vue 自动化覆盖。

补充安全检查：Go 只监听 `127.0.0.1` 随机端口；每次启动使用高熵会话令牌；Electron 开启上下文隔离、关闭 Node 集成并阻止外部导航。
