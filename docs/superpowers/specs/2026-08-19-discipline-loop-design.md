# 开仓前确认与持仓中纪律复核设计

## 目标与边界

本期把本地桌面应用扩展为两个纪律闭环：

1. 合格计划在前往券商交易前，必须完成一次 30 秒开仓前确认。
2. 已持仓证券在应用运行期间按关键价位监控；触线后要求记录一次复核决定。

应用只记录和提示纪律，不向券商发送订单，也不把公开行情当作实时或保证可用的交易信号。应用退出后，监控停止；不新增常驻后台服务。

## 用户流程

### 开仓前确认

计划通过校验后，用户在计划记录中点击“开仓前确认”。页面固定展示证券、计划数量、预计人民币资金、最大计划损失、风险退出价、逻辑破坏条件和计划有效期。

30 秒倒计时结束后，用户须同时确认“不是 FOMO 追涨”“不是为了补回亏损”“不是对浮亏仓位摊平”，才可点击“准备去券商执行”。系统写入一条不可变确认记录，并把计划展示为“已准备执行”。

确认不会替代券商成交。用户仍需在成交补录页记录实际成交；没有计划、未通过计划或计划外成交的既有违规处理保持不变。

### 持仓监控与复核

仅应用处于运行状态时，后端每 10 分钟查询一次有持仓且关联了合格买入计划的证券报价。已实际成交的计划即使过了开仓有效期，仍可作为该持仓的退出规则来源；未关联计划的持仓不自动监控。监控价格来自现有公开报价提供方，界面显示来源和该笔行情的获取时间。

第一期只识别两个结构化价位：

- 当前价格小于或等于计划风险退出价：`risk_exit`。
- 当前价格进入计划的目标/估值退出区间：`target_zone`。

为了支持第二项，计划表单新增可选的“目标/估值退出下限”和“目标/估值退出上限”。两个值必须同时填写，且上限不低于下限；未填写时只监控风险退出价，现有计划继续有效。

首次跨越同一方向的关键线时，系统写入触发记录并向 macOS 发送一条本地通知。价格持续停留在触发区间内不会重复提醒；只有价格恢复到未触发区间后再次跨越，才会产生新提醒。点击通知或在持仓页进入待处理项后，用户必须填写：继续持有、减仓、卖出或暂不操作，以及原因。该复核记录不可覆盖；复核完成后提醒从待处理列表移除。

“继续持有”不改变计划或持仓；若用户随后需要变更计划，仍通过既有修订流程并填写修改原因。

## 架构与数据

Go 后端新增独立的 `monitor` 服务，由 sidecar 启动和停止。它依赖现有市场报价接口、持仓重放结果和计划查询接口；它不持有 UI 状态，也不直接调用 macOS 通知。

Electron 主进程启动后，定期从本地 API 查询未投递的提醒，并通过系统 `Notification` 展示。应用最小化时仍可提醒；退出时 sidecar 与轮询均停止。通知点击事件将主窗口带到“持仓”页的待复核项。

SQLite 新增三类追加式记录：

- `pre_trade_confirmations`：计划 ID、展示的计划快照、三项确认、开始与完成时间。
- `price_alert_events`：计划 ID、证券 ID、触发类型、触发价、关键线与计划退出条件快照、行情来源、行情时间、触发时间、通知投递时间。
- `position_review_events`：提醒 ID、决定、原因、创建时间。

提醒和复核都引用创建时的计划 ID；后续计划修订不篡改历史记录。数据库迁移只新增表和索引，不修改现有成交、计划或审计数据。

## API 与界面

新增本地 API：

- 创建及查询开仓前确认；仅合格、未过期计划可确认。
- 查询监控状态和待复核提醒。
- 完成一条待复核提醒。
- 查询供 Electron 主进程投递的未通知提醒，并在投递后标记。

计划页增加“开仓前确认”入口与“已准备执行”状态；计划表单增加可选目标/估值退出区间。持仓页新增监控状态、最新行情时间、关键线和待完成复核项。设置页新增监控开关与刷新频率选择，第一期可选关闭、10 分钟、15 分钟和 30 分钟，默认 10 分钟。

## 行情失败与安全策略

单次报价失败或报价时间已超过 20 分钟不会产生触发，也不会将缓存旧价用于新的触发判断。后端记录失败时间和简要原因，按退避策略重试，下一次正常轮询仍可继续。持仓页显示“行情未更新”与最后成功时间；通知中始终包含报价时间。

监控只查询当前有持仓且关联合格买入计划的证券，避免不必要请求。没有目标退出区间时只监控风险退出价；没有关联计划、市场关闭、报价过期或公开报价源不可用时，不产生提示。该限制清楚显示在监控状态中。

## 验收与测试

- 合格计划在 30 秒和三项确认完成前不能标记为“准备去券商执行”；确认记录可查询且不可覆盖。
- 计划外、被拒绝或过期计划不能创建确认。
- 报价从未触线到触及风险退出线时，只创建一条对应提醒；价格停留在触发区间内的重复轮询不重复提醒，恢复后再次触线才产生新提醒。
- 达到目标区间只在两个边界完整有效时触发；仅填一个边界会被表单和 API 拒绝。
- 行情失败不新增提醒，持仓页显示最近成功时间。
- 完成复核后待办消失，决定与原因保留；历史计划修订不会改变提醒快照。
- Electron 通知由未投递提醒生成，并在标记投递后不重复发送。
