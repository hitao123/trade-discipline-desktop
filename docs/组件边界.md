# Vue 组件边界

- `App.vue`：只负责桌面壳层、主导航与路由出口。
- `PageHeader.vue`、`ErrorNotice.vue`、`RiskMeter.vue`：共享标题、错误和风险呈现，不持有业务规则。
- 路由视图：组合对应功能组件和 composable，不复制 Go 的资格与风险判断。
- `useRemoteData` 与 `lib/api.ts`：统一加载、错误封装和本地后端会话认证。
- 表单组件：接收初值和校验结果，通过类型化事件提交，不直接改父级状态。
- `useMarketHistory.ts`：编排榜单、市场概览和单只证券历史；控制按需刷新、一次启动内去重和 1/3 个月范围切换，不在前端定时轮询。
- `MarketOverviewPanel.vue`：展示 A 股成交额、南向资金成交净买额及缓存状态，不直接请求数据。
- `InstrumentHistoryPanel.vue`：展示榜单中当前选中证券的本地历史和刷新入口，不改变观察名单或交易计划。
- `MarketLineChart.vue` 与 `lib/chart.ts`：使用原生 SVG 生成可访问折线图和零轴；几何计算保持为纯函数。
- 表格组件：只负责展示和选择；榜单只发出“查看走势”和“加入观察”事件，不提供下单入口。
- 金额、日期和风险比例格式化：放在纯 TypeScript 工具，不建立 composable。
