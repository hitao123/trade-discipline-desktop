# Vue 组件边界

- `App.vue`：只负责桌面壳层、主导航与路由出口。
- `PageHeader.vue`、`ErrorNotice.vue`、`RiskMeter.vue`：共享标题、错误和风险呈现，不持有业务规则。
- 路由视图：组合对应功能组件和 composable，不复制 Go 的资格与风险判断。
- `useRemoteData` 与 `lib/api.ts`：统一加载、错误封装和本地后端会话认证。
- 表单组件：接收初值和校验结果，通过类型化事件提交，不直接改父级状态。
- 表格组件：只负责展示和选择，榜单只发出“加入观察”事件。
- 金额、日期和风险比例格式化：放在纯 TypeScript 工具，不建立 composable。
